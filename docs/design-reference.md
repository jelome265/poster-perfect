## Source

## Inspection status

**Pending.** During the initial documentation pass, neither the supplied Canva editor URL nor its corresponding view URL exposed the design contents to the available read-only inspection method. This is an access limitation; it does not establish that the design or link is invalid.

No visual properties have been inferred from the project name or from assumptions about what a poster-oriented website should look like.

## Required source material

Before design-specific implementation begins, inspect and record:

- A full-resolution export of every relevant Canva page or artboard.
- The original dimensions and aspect ratio of each artboard.
- All copy, text hierarchy, and content order.
- Images, illustrations, icons, logos, and other assets used by the design.
- Font families and weights, including font files or legitimate web-licensing details where required.
- Any links, calls to action, navigation, forms, or other interactive behavior.
- Any existing mobile or alternate-layout variants.

A full-resolution PNG is suitable for visual inspection. A PDF is useful when the source contains multiple pages. Supply separately any source assets that should be used independently in the website.

## Translation rules

1. Treat the inspected design and owner-confirmed requirements as the visual and content references.
2. Record exact copy and preserve its hierarchy. Do not silently rewrite, omit, or invent content.
3. Recreate layout with HTML and CSS rather than using a full-page screenshot as the website, unless an image-only implementation is explicitly approved.
4. Use source assets where available and permitted. Do not substitute unrelated stock imagery or approximate brand assets without approval.
5. Distinguish source properties from web adaptations. Document any change required for responsive behavior or accessibility.
6. Record deviations from the reference and the reason for each deviation.
